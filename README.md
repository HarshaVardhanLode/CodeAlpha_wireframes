# CodeAlpha UI/UX Internship - Task 1

## Task Name

Wireframing & Low-Fidelity Design

## Project

Food App Mobile Application

## Objective

The objective of this task is to create wireframes and low-fidelity designs for a food delivery mobile application. The design focuses on layout structure, user flow, navigation, and screen organization before applying advanced visual styling.

## Tools Used

* Figma

## Screens Designed

1. Splash Screen
2. Sign Up Screen
3. Home Screen
4. Food Details Screen
5. Cart Screen

## Features Included

* App logo and branding
* User registration screen
* Food search functionality
* Food category navigation
* Popular food listing cards
* Food details page
* Shopping cart interface
* Bottom navigation menu

## Learning Outcomes

* Understanding wireframing principles
* Mobile UI layout design
* User flow planning
* Component positioning and spacing
* Figma design fundamentals

## Internship

Submitted as part of the CodeAlpha UI/UX Design Internship Program.
